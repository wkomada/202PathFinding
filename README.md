# 202PathFinding

USAGE:
- Compile and launch file -- no terminal arguments (argv).
- Insert any string when prompted, and a maze based on the binary values of each character in the string (e.g., a = 00001) is generated.
  where 0 bits are converted to open spaces ('.') and 1 bits are converted to blocked paths, or rocks ('#').
- Insert starting and ending coordinates, and the shortest path between those points will be highlighted with green 'P' characters if a path exists.
- Follow the instructions given by the program to try different paths in the same maze, generate a different maze with a new string, or quit.
